    Help — step-by-step guide
    
      
    
        
        
      
    
    
    
    
    
      
    This app measures neurite outgrowth into a scratch wound, entirely in your browser. Nothing is uploaded —
        images never leave your device. It reproduces the measurement pipeline of the desktop Python app v6.7.1.
    

      
    1. Load the reference image
    
      
    Drop (or click to pick) the 0 h post-scratch image in the first box. TIFF, PNG and JPG work.
        The app detects the cell-free scratch gap automatically and places a rectangular region of interest (ROI)
        over it. You can also press Load demo images to try the app with the bundled example data.
    

      
    2. Load the images to analyse
    
      
    Drop the later time-point images in the second box. Each one starts with a copy of the reference ROI and can
        then be adjusted on its own. Select an image with the drop-down above the viewer or by clicking it in the
        list or the results table.
    

      
    3. Check and adjust the ROI
    
      
    In the ROI tab, drag any of the four corner handles to reshape the quadrilateral, or drag
        inside it to move the whole shape. Zoom with the mouse wheel or the −/Fit/+ buttons. The side lengths and
        the area are shown live next to the ROI tools. Auto-detect gap re-runs the automatic
        detection on the reference, Use reference ROI resets the current image to the reference ROI,
        and Apply reference ROI to all copies it to every image.
    

      
    4. Set the detection parameters
    
      
      
        
    • Top-hat size — size of the square structuring element used by the top-hat filter that
          enhances thin, bright structures (odd values 3–51, default 15).
      • 
        
    • Otsu offset — shifts the automatic Otsu threshold up or down (−50…50, default 0).
      • 
        
    • Manual thresh — fixed binary threshold 1–255; set to 0 to use the
          automatic Otsu threshold plus the offset instead (default 100).
      • 
        
    • Min area — connected components smaller than this many pixels are discarded as noise
          (default 150).
      • 
        
    • Min length — skeleton traces shorter than this many pixels are discarded (default 50).
      • 
        
    • Pixels per micron — your image calibration; converts pixel lengths to µm and areas to µm²
          (default 0.287).
      • 
      
    
      
    The Threshold preview tab updates live and shows the exact binary image the pipeline will
        measure, so you can tune the parameters before running.
    

      
    5. Run the analysis
    
      
    Press Run analysis. Each image is processed with the real pipeline: ROI masking, histogram
        equalisation, inversion, top-hat, blur, threshold, size filtering, skeletonisation and tracing. The results
        table fills in below the viewer; hover a column header for its definition. If you change the ROI or a
        parameter afterwards, affected rows turn grey until you run again.
    

      
    6. Overlay and scale bar
    
      
    The Overlay tab paints the detected neurites on the image. Choose the background
        (Color, Grayscale or B/W), the neurite colour and the painted thickness — these are
        presentation only and never change the numbers. Optionally add a scale bar (length, corner, label and colour)
        to the exported overlays.
    

      
    7. Export
    
      
    Press Export results (ZIP) to download a single ZIP containing results.csv,
        results.xlsx and one overlay PNG per analysed image.
    

      
    Tips
    
      
      
        
    • Your settings are saved in the browser and restored next time; Reset settings to defaults
          puts everything back.
      • 
        
    • Use the Tutorial button (top right) for an interactive walkthrough of every control.
      • 
        
    • Use the sun/moon button (top right) to switch between light and dark mode.
